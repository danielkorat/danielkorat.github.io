# danielkorat.github.io

Personal website of Daniel Korat. A single hand-written page (`index.html`), no build step; GitHub Pages serves it as-is (`.nojekyll`).

- Edit `index.html`, commit, push to `main`; the live site updates within a minute or two.
- Photo: `img/portrait.jpg` (square crop of `Daniel_Korat_headshot_white-bg_827x793.jpg`, Google Drive › Photos & Videos › Profile Pics).
- Light/dark mode follows the visitor's system setting; the ◐ button overrides it.
