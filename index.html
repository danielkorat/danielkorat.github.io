01Selected work

2023–2025
Inference

Speculative decoding with any assistant model

Co-developed three methods, Dynamic Speculation Lookahead, Universal Assisted Generation and Token-Level Intersection, merged into Hugging Face Transformers; Token-Level Intersection is also in vLLM, where it is the only cross-tokenizer drafting path. Up to 2.8× faster generation with no change in output. First author on Universal Assisted Generation, which lets a small model draft for a large one even when their tokenizers differ.

ICML 2025 paperHF blog: UniversalHF blog: DynamicHF blog: TLI

2025–2026
Agents

Cost-efficient AI agents

Built and shipped a Claude Code plugin in which a frontier model hands work to a local specialist model served on commodity CPU servers: up to 24% lower operating cost than cloud-only, at equal latency. Built a deep-research agent that runs fully on-premises across CPU and GPU; profiling each stage led to a redesign that cut about 51% of the tokens per query.

hybrid-deep-research

2022
Few-shot

SetFit: few-shot text classification without prompts

Co-created with Hugging Face: train a strong classifier from a handful of labelled examples. 2M+ downloads a year; a later 8-bit version runs 7.8× faster on CPU.

GitHubPaperHF blog: 7.8× on CPU

Portfolio Beam Search

Spends a fixed test-time compute budget across several search strategies. At 16 beams it matches standard beam search at 32.
